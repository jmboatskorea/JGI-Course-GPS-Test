JGI WHOOP Pilot 개인정보 안내

적용일: 2026년 10월 7일

사용 목적과 동의

사용자가 동의하고 WHOOP에서 접근을 승인한 경우 Recovery, Sleep, HRV, Resting HR, Day Strain을 받아 라운드 전 상태 참고와 보수적인 플레이 행동 한 가지를 표시합니다. Live HR는 별도 Bluetooth 기기 선택 및 권한 허용 후 수신합니다. 개인 건강 진단이나 심박만으로 피로·과부하를 판정하는 용도로 사용하지 않습니다. WHOOP를 연결하지 않아도 라운드를 이용할 수 있습니다.

저장과 보호

라운드 시작 전 today snapshot은 현재 브라우저의 라운드 localStorage에 저장할 수 있습니다. Round DB, player_id 또는 장기 wearable 서버 저장소로 전송하지 않습니다. 기존 라운드 기록에 포함된 snapshot은 해당 기록과 함께 브라우저에 남을 수 있습니다. Live HR와 최근 5분 추이는 페이지 메모리에만 유지되고 새로고침하면 지워집니다.

WHOOP 자격증명은 서버 환경변수로만 관리합니다. OAuth/refresh token은 서버에서 암호화한 Secure·HttpOnly 쿠키로 최대 24시간 유지하며 브라우저 JavaScript나 localStorage에서 접근할 수 없습니다. 서버는 요청 처리와 토큰 갱신에만 이를 사용합니다.

연결 해제와 삭제

BODY의 WHOOP 연결 해제 버튼을 누르면 서버가 WHOOP 접근 권한 해제를 요청하고 세션 쿠키를 삭제합니다. 요청 실패 시 WHOOP 앱의 Integrations에서 직접 해제하라는 안내를 표시합니다. Live HR 해제 버튼은 Bluetooth 수신을 중단합니다. 이미 저장한 라운드 snapshot도 삭제하려면 해당 사이트의 브라우저 저장 데이터를 삭제할 수 있습니다. 이 경우 다른 로컬 라운드 기록도 함께 삭제됩니다.

판매 및 공유

JGI는 WHOOP 데이터와 Live HR 데이터를 광고주에게 판매하지 않습니다. WHOOP API 요청은 사용자가 승인한 데이터 조회를 위해 WHOOP 서버와 통신합니다.

문의 방법

이 Pilot 접근을 안내한 JGI 담당자에게 기존 안내 채널로 문의해 주세요. 전용 개인정보 문의 주소는 아직 설정 대기 중입니다. WHOOP 계정 접근 권한은 WHOOP 앱에서도 관리할 수 있습니다.
